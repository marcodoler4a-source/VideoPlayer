VIDEO PLAYER — GITHUB UPLOAD

IMPORTANT:
VideoPlayer.xcodeproj is a FOLDER/package. GitHub's web page cannot reliably upload that folder by dragging the .xcodeproj item itself.

RECOMMENDED (iPhone/iPad or computer):
1. Extract this ZIP.
2. Create/open your GitHub repository.
3. Use GitHub Desktop or git to commit the WHOLE extracted folder.

COMMAND-LINE METHOD:
  git init
  git add .
  git commit -m "Initial VideoPlayer with SRT support"
  git branch -M main
  git remote add origin YOUR_GITHUB_REPOSITORY_URL
  git push -u origin main

IF YOU MUST USE GITHUB WEB UPLOAD:
Upload the normal root files and VideoPlayer source folder first. For the Xcode project, GitHub must preserve these exact paths:
  VideoPlayer.xcodeproj/project.pbxproj
  VideoPlayer.xcodeproj/xcshareddata/xcschemes/VideoPlayer.xcscheme

Do NOT rename VideoPlayer.xcodeproj and do NOT upload project.pbxproj into the repository root.

CODEMAGIC:
The included codemagic.yaml expects:
  VideoPlayer.xcodeproj
  Scheme: VideoPlayer
It creates build/VideoPlayer-unsigned.ipa.
